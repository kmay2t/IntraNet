Parámetros del módulo Gestión

Cada cuántos días debe entregar un reporte de estatus el ingeniero responsable. Es el valor por defecto que se aplica al asignar un ticket cuando no se indica una periodicidad propia.

Fecha límite

Con la opción habilitada, el Administrador puede fijar la fecha límite de actividades, incidentes y tickets, y los elementos abiertos fuera de tiempo se marcan como vencidos. Con la opción deshabilitada la fecha límite no se solicita, no se guarda ni se valida para los registros correspondientes. Esta configuración es exclusivamente administrativa: el Ingeniero no ve el campo en ningún caso.
